## Yang perlu dilengkapi

Setelah denah tersedia, lengkapi bagian berikut bersama pembimbing:

- [ ] **Pembagian zona.** Misalnya zona penerimaan, zona penyimpanan per kelompok material, zona karantina, dan zona pengeluaran.
- [ ] **Penomoran rak dan lokasi.** Cara membaca kode lokasi yang tercatat di master material.
- [ ] **Area khusus.** Lokasi penyimpanan consumable seperti oli dan grease, APD, serta barang berat.
- [ ] **Jalur dan pintu darurat.** Lokasi alat pemadam api ringan (APAR) dan titik kumpul.
- [ ] **Area terbatas.** Bagian yang tidak boleh dimasuki peserta magang tanpa pendamping.

## Cara mengganti gambar
