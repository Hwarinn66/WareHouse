# FAQ

<p class="lead">Jawaban singkat untuk pertanyaan yang sering muncul. Klik pertanyaan untuk membuka jawabannya.</p>

Pertanyaan yang belum memiliki jawaban resmi ditandai **Menunggu jawaban pembimbing**. Untuk pertanyaan seperti itu, tanyakan langsung kepada pembimbing magang.
